# Architecture Decision Records

Architecture Decision Records capture choices that affect public contracts,
durable data, compatibility, repository structure, or operations.

Status values are `Proposed`, `Accepted`, `Superseded`, and `Rejected`. A
decision is changed by adding a new ADR that supersedes the old one; accepted
records are not silently rewritten.
